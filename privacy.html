FrameGate 개인정보처리방침

시행일: 2026년 9월 21일

1. 처리하는 정보

FrameGate는 연결을 위해 사용자가 승인한 외부 플랫폼의 접근 토큰과 계정 식별 정보를 로컬 컴퓨터의 설정 파일에 저장할 수 있습니다. 영상 파일과 제작 자료는 사용자의 로컬 컴퓨터에 저장됩니다.

2. 이용 목적

이 정보는 사용자가 요청한 계정 연결, 승인된 영상의 게시 및 게시 상태 확인에만 사용됩니다.

3. 외부 제공

사용자가 게시를 실행한 경우에만, 게시에 필요한 영상·제목·설명 및 인증 정보가 해당 소셜 플랫폼으로 전송됩니다. FrameGate는 정보를 판매하거나 광고 목적으로 제공하지 않습니다.

4. 보관과 삭제

사용자는 언제든지 로컬 설정 파일에서 연결 토큰을 삭제하거나 해당 플랫폼에서 앱 연결 권한을 철회할 수 있습니다. 토큰을 삭제하면 이후 자동 게시와 상태 확인이 중지됩니다.

5. 보안

사용자는 토큰과 비밀번호를 타인에게 공유하지 않아야 합니다. 공용 컴퓨터에서는 사용 후 로그아웃하고 로컬 파일 접근을 제한해야 합니다.
